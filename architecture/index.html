Key Concepts

Component CMS

Editors don't write HTML. They compose pages from UI-kit components (sliders, tables, cards, etc.) in a visual editor. The editor saves component trees as XML. A Scala transpiler converts XML to static HTML using rules defined in components.json.

XML → HTML Pipeline

Source XML lives in website/XML/. When an editor publishes, the transpiler converts XML to HTML, stores it in website/HTML/, and lsyncd automatically rsyncs it to root2 where nginx serves it to the public.

Two-Server Architecture

root1 (bifrost) runs all application logic in Docker. root2 (edith) is a pure static nginx server. They're connected by lsyncd — 5 continuous rsync streams over SSH that keep published content, Josh user sites, and nginx configs in sync.

ConfMan

The Configuration Manager generates nginx reverse proxy configs dynamically. When admins approve a subdomain (like cec.iitr.ac.in), ConfMan writes an nginx server block, lsyncd pushes it to root2, and inotifywait auto-reloads nginx. Zero manual config.
