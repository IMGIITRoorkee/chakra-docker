Frontend (Next.js)

Next.js editor UI — visual page composition from UI-kit components

Container Overview

The frontend runs in a Docker container using the chakra-frontend:latest image. It serves the editor interface on port 3000, proxied by nginx on root1.

Startup Command

yarn build && pm2 start yarn --name "nextjs" -- start && pm2 monit

Runtime

  • Port: 3000
  • Process manager: PM2
  • Proxy: Nginx on root1 forwards /* fallback to :3000
  • PROXY env var: chakra.channeli.in

Dev Server

./scripts/run-dev.sh -d 60000 -p 61000

Runs Next.js dev mode inside Docker on high ports for local development.

What It Does

The frontend is a visual editor for composing pages from pre-built UI-kit components. Editors drag and arrange components, and the frontend generates XML from these component trees.

PagePurpose
EditorVisual component composer — drag, arrange, and configure UI-kit components
Page ManagementCreate, list, edit, and delete pages
Folder BrowserNavigate the website directory structure
File UploadUpload images and assets for pages
PermissionsManage user access and roles

Backend Integration

The frontend communicates with the Django backend using axios with credentials enabled for all API calls. Key integration points:

Image Picker

GET /api/generator/image?xml_page_pk={id}

Lists available images for a given page. The editor displays these in a picker UI so editors can insert images into their component trees.

Preview

GET /api/generator/preview/?xml_page_pk={id}

Requests a rendered HTML preview of the current page. Django calls the transpiler, which returns HTML with absolute asset URLs for display in the browser.

API Client

All backend requests go through a centralized axios instance configured with credentials and the correct base URL.

// Axios instance configuration const api = axios.create({ baseURL: `https://${PROXY}/api`, withCredentials: true, });

The PROXY environment variable is set to chakra.channeli.in in production, ensuring all API calls route through the main nginx reverse proxy.

Component Workflow

The editor generates XML from the visual component tree. This XML is saved to the backend and later transpiled to HTML.

1

Compose

Editor arranges UI-kit components in the visual editor interface.

2

Generate XML

Frontend serializes the component tree into XML format.

3

Save

XML is sent to Django backend and stored in website/XML/.
