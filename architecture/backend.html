Backend (Django)

Django application server — APIs, auth, file management, and publish workflow

Container Overview

The backend runs in a Docker container using the chakra-backend:latest image. Inside the container, supervisord manages three long-running processes that together handle HTTP requests, WebSocket connections, and background tasks.

Startup Command

source chakra_backend/.env && supervisord -c /supervisord.conf

Process Management (supervisord)

Supervisord keeps all three processes running and restarts them on failure. Each process binds to a different port on the host network.

HTTP

Gunicorn

Port 8000. 5 workers, gthread worker class, 120s timeout. Handles all Django REST API traffic.

WS

Daphne

Port 8001. ASGI server for WebSocket connections. Powers real-time editor features.

BG

Celery

Background task worker. Uses RabbitMQ as message broker. Runs scheduled cron jobs and async tasks.

Nginx on root1 routes incoming requests to the appropriate backend process based on URL prefix.

Celery Cron Jobs

Celery Beat schedules periodic tasks via RabbitMQ. These run automatically without manual intervention.

ScheduleFunctionPurpose
Every 60 mingenerator.cron.my_scheduled_jobRuns tmp_clear.sh — deletes preview images older than 1 day
Every 720 mingenerator.cron.notice_list_publish_cronAuto-publishes notice list pages
